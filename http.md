1. Что такое HTTP-метод?
HTTP-метод — это действие, которое клиент просит сделать сервер.
Основные:
GET — получить данные;
POST — отправить/создать данные;
PUT / PATCH — обновить данные;
DELETE — удалить данные.

2. Чем GET отличается от POST?
GET:
запрашивает данные;
обычно не меняет сервер;
параметры могут быть в URL.

POST:
отправляет данные на сервер;
часто создаёт что-то новое;
данные обычно находятся в теле запроса.

Что такое статус-код?
Статус-код — это числовой ответ сервера.
Основные группы:
2xx — успех;
3xx — перенаправление;
4xx — ошибка клиента;
5xx — ошибка сервера.

Примеры:
200 OK
201 Created
400 Bad Request
401 Unauthorized
403 Forbidden
404 Not Found
500 Internal Server Error

Что такое HTTP-заголовок?
Заголовок — это дополнительная информация о запросе или ответе.
Примеры:

Content-Type: application/json
Authorization: Bearer token
Accept: application/json

Что такое JSON?
JSON — текстовый формат данных.
Пример:

{
  "id": 1,
  "title": "First post",
  "userId": 1
}
